## Decisions Made

1. **D137:** Hybrid LLM interaction — CLI (subscription) AND API (direct billing) via existing adapter+plugin pattern. Start with Claude CLI agentic mode. Architecture supports any provider.
2. **D138:** Full sub-agent architecture — Claude Code pattern. Main Orchestrator + 7 phase-specific sub-agents with specialized prompts, restricted tools, structured JSON output.
3. **D139:** Iterative development — build each phase, manually test, refine, repeat. Thoroughness over speed.
4. **D140:** Smoke test baseline — run system as-is before any changes to establish concrete "before" behavior.
5. **D141:** Per-phase tool restrictions — maps Permission Table action classes to Claude Code tools. Principle of least privilege at LLM level.
6. **D142:** Prompt templates in TypeScript — separate files in `src/core/orchestrator/prompts/`, type-safe context injection.
