8. #97 — Duration parsing via `ms` package ("4h" → 14400000)
9. #98 — tsconfig: maximum strictness (noUncheckedIndexedAccess, exactOptionalPropertyTypes)
10. #99 — Biome `all` preset, carve exceptions (noExplicitAny: error)
11. #100 — lefthook for git hooks (Go binary, YAML config, parallel)
12. #101 — Enforcement pipeline: pre-commit (Biome + tsc parallel), pre-push (Vitest)
