## Decisions Made

1. **Scope: fix/complete everything** — not document-only; large, so planned as a multi-session breakdown.
2. **Dedup → Core via `idempotency_key`** (Option A) — durable on the task row; `external_ref` demoted to descriptive; namespaced by source. Every trigger gets crash-safe exactly-once.
3. **Delete vestigial `trigger.pr_review`** — zero producers/consumers; the real review loop lives in `review-handler.ts`. Review polling → Slice 10.
4. **Core `StateStore`** — minimal opaque KV, DB-backed (`plugin_state` table), `--home`-aware. Watermark/ETag become efficiency, not correctness.
5. **PluginContext (centerpiece)** — consolidate the scattered `unknown`-typed injected fields into one typed context (logger + stateStore + hookRegistry); keep `this.manifest` (principled split). Per-plugin-tagged logger. The reusable foundation for Slices 8/10/12 + npm SDK.
6. **Per-plugin poll cadence** — numeric `poll_interval_ms` typed manifest field; manifest-default + global fallback; **no** per-plugin override map (YAGNI for single-user v1).
7. **Configurable work selection** — assignee/label/both; require ≥1; rename `event_type`.
8. **Core owns poll backoff** — plugin reports `retry_after_ms`; daemon honors it; remove plugin `retryAfterUntil`.
9. **Single-user v1 constraint** — assume exactly one human user (the owner). Does NOT relax multi-task concurrency or Plugin Blindness. → new `docs/constraints.md`, referenced from README + AGENT-README. Memory saved.
10. **People-directory: warn, don't collapse** — shared by 10 consumers; load-warn on >1 person / no owner; outreach targets owner; `engineer doctor` validates owner channels.
11. **telegram chat-map → StateStore migrated in Slice 5** (opportunistic, persistence-adoption ≠ comm-flow).
12. **Cross-slice handoffs deferred** — #9 reply-token correlation + #10 unblock sender check → Slice 12; trivial-skip handoff → Slice 8; review polling → Slice 10. Designed here, executed there.
13. **Expert-panel review deferred** to the start of the implementation session (fresh context), not skipped.
