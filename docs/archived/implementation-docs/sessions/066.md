# Session 066 — 2026-03-22

## What Happened

Massive session with three major deliverables. (1) CLI-Only LLM Pivot — removed all API-oriented LLM abstractions, replaced CompletionRequest/CompletionResult with InferenceRequest/InferenceResult, renamed complete()/doComplete() to infer()/doInfer(), unified cost tracking. (2) Three-layer usage & quota tracking — enriched InferenceResult with per-call token/cache breakdown, added getQuotaStatus() to LLMAdapter, switched Claude Code plugin to stream-json --verbose for rate_limit_event parsing, wired updateTracking(), added cost.quota_exhausted event, token accumulation in cost tracker, dashboard token/quota display with session + long-term cards. (3) Quota API integration — discovered Anthropic's /api/oauth/usage endpoint for real quota percentages, integrated with cross-platform credential access (macOS Keychain + file fallback), 30-min caching for rate limit protection. Also: plugin docs restructured into llm-adapter/ directory with LLM-guided setup prompt, OS-specific plugin selection added to future-considerations.md. 11 commits, 55+ files, 2399 tests.

## Decisions Made

1. Dashboard testing skipped entirely — deferred to Dashboard Full Rebuild at end of Layer 8
2. New roadmap phase: Multi-CLI Plugin Integration (after CLI-Only LLM Pivot, before RPI Integration)
3. Three-layer usage contract: per-call usage (InferenceResult.usage), quota status (getQuotaStatus()), limit detection (is_rate_limited) — all optional, plugins implement what they can
4. Claude Code plugin uses stream-json --verbose to get both result + rate_limit_event data
5. Quota API (/api/oauth/usage) cached for 30 minutes due to aggressive per-token rate limiting (~5 requests before 429)
6. Dashboard is pure data reader — never makes API calls itself. Plugin gets data, Core stores it, dashboard reads
7. observe() stores data in `input` field (not `output`); output is for span end-data only
8. Plugin docs use LLM-guided setup prompts — users point their LLM at the prompt.md and it handles OS detection, credential setup, config generation interactively
9. Plugins are currently macOS-only; OS-based plugin selection documented as future consideration
