## Decisions Made

1. **Reaper `runOnce` is async** (Q&A-confirmed). data-lifecycle (the shape mirrored) is synchronous, but it
   is a pure DB janitor; the reaper does fallible network git work, and Session 3 drops an async `closePR` into
   the same sweep. Async now makes the re-entrancy guard real and avoids a Session-3 signature churn. Its S2 body
   is synchronous, so `reapTask` carries a documented `biome-ignore lint/suspicious/useAwait` naming the S3 seam
   (biome 1.9.4's `useAwait` is on under `all: true`; the suppression is load-bearing, confirmed by a clean gate).
2. **The remote-delete timeout + already-gone tolerance live in the `deleteRemoteBranch` primitive** (Q&A-confirmed),
   not a reaper wrapper. `execFileSync` can't be interrupted by a JS timeout, so the bound must be the exec's own
   `timeout` option; and "already-gone = success" is a property every caller wants (idempotent delete), mirroring
   how `cleanupWorkspace` already tolerates a missing local branch. The reaper owns the higher envelope
   (retry-counter→alert, per-task isolation, `getLastRun`). Verified against a real bare remote.
3. **`reaped_at` had to become a writable field** — `updateTaskField`'s `UpdatableField` union + `FIELD_TYPES`
   omitted it, and the reaper must write it. (Plan under-count #1.)
4. **The unreaped-terminal query needs interface + facade exposure**, not just `queries.ts` —
   `taskEngine.getUnreapedTerminalTasks()` is called by the reaper. Built from `TERMINAL_STATES` minus `failed`
   (the one deliberate exclusion: failed is preserved for debug + retry, D4). (Plan under-count #2.)
5. **The external-merge backfill records `git.pr_merged` with `merge_sha: ""`** — `PRStatus` carries no SHA, so
   "" is the honest sentinel (consistent with the existing `into_branch ?? ""`); strategy is the configured default.
6. **The live `pr-management/overview.md` user-flow doc rode with the code** — it still claimed auto-merge deletes
   the branch and that the orchestrator publishes `git.branch_deleted`; corrected in-commit (docs ride with code,
   DoD #7). The archived implementation docs and the slice/plan files were left intact (forward-only docs).
