## Decisions Made

1. **Two-pass review discipline confirmed.** First pass found ~10 small things across one workspace-manager file and surrounding docs. Farzam pushed for a deeper second pass: "how well you do this phase is about how effective you review which is hard for LLMs." Second pass found the dead `ephemeral.ts` surface, the backward-compat re-exports, the dual-source-of-truth `PendingPreemption`. The lesson is structural: a single linear read against the standards is insufficient; the principle-driven hunts in `approach.md` must each be a deliberate query, not a passive expectation. Reinforces the slice-closing-sweep methodology already in `approach.md`.

2. **`schemas/ephemeral.ts` reduced to just `Dispatch*`.** Audited every export, found 18 with zero src/ consumers. Several literally described the in-memory worktree Map killed in Session 35. `PendingPreemption` was defined twice with different field shapes (snake_case + ISO datetime in the dead schema, camelCase + epoch number in the runtime interface). Cut everything except `Dispatch`, `DispatchSchema`, `DispatchPayload`. Three config imports went with them (`DaemonConfigSchema`, `SafetyConfigSchema`, `WorkspaceConfigSchema`). Net -578 lines. Test file trimmed to just the `DispatchSchema` tests.

3. **Backward-compat re-exports deleted as a category, not piecemeal.** Two test-only re-exports existed with explicit `// Re-export for backward compatibility` comments: `PHASE_SEQUENCE` in `phase-runner.ts` and `isSlotConsuming`/`shouldPreempt` in `daemon/index.ts`. `approach.md`'s Universal Rules ban backward compat outright pre-v1. Tests updated to import from real sources. Adjacent finding flagged: LLM plugins have similar "retained for backward compatibility + tests" patterns, parked for Slice 8 (those are LLM-domain).

4. **`removeThoughtsAndPush` should throw the domain error class.** The function was relocated from workspace-manager to pr-manager in Session 34 and lost the `WorkspaceNotFoundError` import in the move, falling back to bare `Error`. Restored the domain class via direct import from `workspace-manager/errors` (no circular dep: errors.ts has no imports of its own).

5. **`session-result/index.ts` swallowed catch surfaced via process.stderr, not observer.** The module is module-level pure functions (no observer in scope, would require threading observer through all callers). Used the doctor.ts pattern from the Slice 5 sweep: `process.stderr.write` with the failure consequence (stale file persists, will mask the next CLI session's output) named explicitly.

6. **Commit messages: no em dashes, ever.** After landing the four sweep commits with em dashes throughout titles and bodies, Farzam called it out hard ("em dashes are an LLM tell"). Used `git reset --hard HEAD~4` + cherry-pick onto `backup-sweep-em-dashes` to rewrite each commit's message with colons instead. Backup branch deleted after verification. Memory captured as `feedback_no_em_dashes_in_commits.md`. Rule applies forward to every commit on this project.
