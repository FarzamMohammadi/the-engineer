## Decisions Made

1. `findRepoRoot` walk-up replaced with a fixed relative resolve from `import.meta.url` (`path.resolve(MODULE_DIR, "../../..", "resources", "skills")`). Same depth in src/ and dist/, zero filesystem calls, declarative — the walk-up was over-engineered for a known relative position.
2. `SkillsManager` lives in `CoreComponents` (constructed in `system.ts`) rather than only on `OrchestratorContext`. Centralizes wiring with the other Core services and matches the existing pattern for WorkspaceManager.
3. `removeThoughtsAndPush` exported as a standalone function from `pr-manager.ts` (not via the `createPrManager` factory closure). Narrow `{workspaceManager, observer}` deps shape lets review-handler call it directly without needing a full PrManager instance — avoids duplicating PrManager construction in the daemon wiring.
4. `gitExecWithAuth` kept its name (not renamed to `fetchWithAuth`) — followed the plan's "in-place simplification, minimize churn" default. The dead `push` branch was dropped; the helper is now unconditional auth injection for any args containing `origin`.
5. SSOT refinement (scope addition): hoisted the `workspace_root` tilde expansion from WorkspaceManager's constructor into `system.ts` so SkillsManager + WorkspaceManager receive the same canonical expanded path. Removes the duplication that would have appeared by re-implementing tilde expansion inside SkillsManager. ~6-line change, contained, preserves behavior.
6. `core/session-result/` deliberately omitted from the bootstrap "Core components created" log — the log enumerates instances, and session-result is module-level pure functions with no instance.
