   `"Cancelled via dashboard"`; every other transition reason is a snake_case token (`cli_cancel`,

   dispatches). `usage-guide/writing-tickets.md`'s label list was deliberately left untouched —
   documenting a label that is never applied would be a lie. Recorded in `active.md` → Deferred → Slice 10.

   stale (Session 1's added comments pushed the index to line 85). Switched to the index *name*
   `idx_tasks_idempotency_key_active`, which does not rot.
