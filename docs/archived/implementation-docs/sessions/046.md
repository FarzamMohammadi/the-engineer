### Process Safety Rules Implemented (Decision #108)

| Rule | Implementation |
|------|----------------|
| Rule 1: Explicit shell | `spawn("bash", ["-c", cmd])`, never `shell: true` |
| Rule 2: Signal forwarding | Track `Set<ChildProcess>`, SIGTERM → SIGKILL after 5s grace |
| Rule 3: Workspace confinement | `cwd` always set to `context.workspace_path` |
| Rule 4: Env sanitization | Allowlist: PATH, HOME, NODE_ENV, LANG, TERM, GIT_* + configurable passthrough |
| Rule 5: Output limits | Configurable max_output_bytes (default 10MB), process killed if exceeded |
| Rule 5: Command timeout | Configurable command_timeout_ms (default 5min), process killed if exceeded |
