### Key Design Decisions

- **ENGINEER_HOME as first-class concept** — resolved once per command via `resolveEngineerHome()`, passed explicitly. Flag > env > default (`~/.engineer`).
- **Bootstrap separate from start** — `bootstrap()` wires all 12 components, returns `{ daemon, logger, cleanup }`. Reusable by Phase 15 integration tests.
- **Doctor checks are pure functions** — each takes explicit params, no global state. Pre-flight subset (categories 1-6) reused by `start` command.
- **Static templates over Zod introspection** — templates include comments, grouping, docs that schemas can't produce. 11 hand-crafted YAML templates.
- **pino-pretty → runtime dependency** — `engineer logs` needs it at runtime for human-readable output.
- **No IPC for status** — reads SQLite directly (read-only). Plugin health unavailable in v1 (deferred to Phase 14b).
- **Background mode via re-spawn** — `--daemon` forks a detached child process with `--_foreground` flag.
