## Issues Found & Resolved

1. **`per_repo` cost limit ghost (Decision #126):** `cost.limit_reached` event had `per_repo` in its `limit_type` enum, but no per-repo cost limit existed in `SafetyConfigSchema`. Also `daily_global`/`monthly_global` naming didn't match config's `daily`/`monthly`. Fixed: removed `per_repo`, renamed to match config.

2. **Action Pipeline missing from layout (Decision #127):** Central L3 concept (Gate 1 → Gate 2 → Execute → Notify) owned the `action.rejected` event but had no module in the project layout. Fixed: added `src/core/action-pipeline/index.ts`.

3. **`config.reloaded` ghost event:** layout.md referenced a `config.reloaded` event that didn't exist in the 30-event catalog. Fixed: changed to "log reload at info level."
