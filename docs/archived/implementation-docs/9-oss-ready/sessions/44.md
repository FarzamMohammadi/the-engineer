## Decisions Made

1. **`pr_workflow_failed` → `pipeline_failed`** *(Farzam's pick)*. The five failure categories
   (`no_result`/`details_invalid`/`agent_failed`/`orchestrator_error`/`iteration_cap_hit`) collapse to
   one generic-failure routing reason; the old name lied now that failures span the whole pipeline.
   `awaiting_pr_review`→`pr_review_pending`, `agent_unavailable`→`agent_unavailable`,
   `awaiting_human`→`need_more_info` map one-to-one.
2. **`BlockedDetails` reshaped to typed keys** *(Farzam's pick)* — `{reason, category, sub_phase,
   needed}`, dropping the legacy outreach fields (`efforts_made`/`contacted`/`waiting_for`). D9's
   queryable dimensions; outreach's "who was contacted" became `outreach-sender`'s own concern.
3. **The `pr-manager` PR-creation cluster deleted now, rebuilt in S7** *(Farzam's pick)*. `push`
   absorbed the commit-and-push mechanics; `createPullRequest`/`composePrBody`/`formatTriggerReference`
   lost their only caller and would have been knip-dead, so they go and S6/S7 rebuild create-pr against
   the finalized task state. `removeThoughtsAndPush` stays.
4. **Held the line at `push`** *(the Session 4 flag)*. `create-pr`/`auto-merge`/`await-review` re-entry
   stay shelled until S6's `detectPrEvents` + S7's wiring.
5. **The runner persists task position live** (legacy-consistent, keeps `engineer status` accurate and
   feeds the S13 dashboard); the dark harnesses got a no-op `updateTaskField`. **Resume re-runs the
   checkpointed sub-phase** — re-applying its route reproduces the original flow, which is simpler and
   correct vs. trying to record the post-route cursor.
6. **Outreach delivery kept and wired into the block path.** `executeTask` calls `sendOutreach` on an
   `awaiting_human` block (the requirements `gather` writes the outreach files); the legacy "no contacts
   → proceed without blocking" escape moved into the gather prompt (it is told not to ask when no
   contact exists), so the wiring just delivers best-effort then blocks.
