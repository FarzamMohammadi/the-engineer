# Session 037 — 2026-03-10

## What Happened

Implemented Phase 5 (Adapter Base Classes + SDK Boundary) — the contract surface between Core and Plugin tiers. Created the abstract class hierarchy (`BaseAdapter` → 5 type-specific adapters) with template method pattern for all async I/O methods, capability-gated optional methods on `CommunicationAdapter` (default-throw pattern instead of TypeScript `?` syntax), and a curated SDK boundary at `src/adapters/index.ts`. Found and resolved 6 discrepancies between the L3, L4, and L5 architecture specs through collaborative discussion. Added `ToolExecutionContext` (workspace_path + task_id) for per-call workspace confinement. 9 source files, 8 test files, 114 new tests, all verification passes (tsc, biome, vitest). Total: 584 tests across 20 test files.

## Decisions Made

1. **Template method depth**: All async I/O methods get template wrapping (`do*` pattern). Sync pure methods (`formatMessage`, `describe`, `getCapabilities`) stay as direct abstract — no wrapping overhead for pure data transforms.
2. **Optional method pattern**: Default implementations that throw descriptive `AdapterMethodError` with code `"capability_not_available"`. No TypeScript `?` optional syntax, no `!` assertions. Core checks `hasCapability()` before calling; forgotten checks yield a clear error.
3. **ToolAdapter.describe() singular**: Follow L3 (authoritative) — one plugin = one tool = one description. L5's plural `ToolDescription[]` was an error.
4. **CommunicationAdapter issue management**: Three separate methods (`commentOnIssue`, `createIssue`, `updateIssue`) per L3, not L5's consolidated `doManageIssueLabels()`.
5. **ToolExecutionContext added**: New schema type (`workspace_path`, `task_id`) passed per `execute()` call. Enables workspace confinement (Decision #108) without shared mutable state in plugins.
6. **healthCheck timeout deferred**: BaseAdapter wraps `doHealthCheck()` for error catching only. Timeout logic deferred to Registry (Phase 6) where `health_check_timeout_ms` config already exists.
