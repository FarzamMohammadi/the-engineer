Every pipeline failure blocks with a unified typed `BlockDetail` whose `category` is a single complete `BlockCategory` (failures and waits, never null); crashes keep retry-policy's backoff (untouched). Deliverable is config-driven (PR mode = merged PR; push-only = pushed branch). Migration is build-dark-then-atomic-cutover (no parallel runners).
