## Decisions Made

1. Plugin Opacity codified in `docs/philosophy.md` — the single most important architectural principle
2. Fresh Project, Local-Only codified in `8-refinement-v2/status.md` — no backward compatibility tax, clean breaks always
3. Priority extracted from ticket body via `@priority: <number>` — replaces label-based config mapping. Platform-agnostic, zero plugin config, extensible via `extractEventVariables()`
4. `issue_management` → `ticket_management` capability rename. `commentOnIssue(repo, number, comment)` → `commentOnTicket(externalRef, comment)`. All Core "issue" language → "trigger ticket"
5. Owner must always exist — add doctor/pre-flight check. Validate at startup, not outreach time.
6. `sendOutreach` returns `OutreachResult` (delivered/not-delivered with reason). Phase runner decides blocking based on result.
7. `externalRefsMatch` stays type-agnostic (for unblock), `findByExternalRef` is type-aware (for dedup) — deliberate divergence
8. `contacted` preserved on unblock by clearing sub-fields individually, not nulling entire blocked object
9. `orchestrator-notifier.ts:39` plugin ID construction identified as Plugin Opacity violation — fix via Registry lookup
