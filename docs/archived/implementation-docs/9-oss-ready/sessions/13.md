## Decisions Made

1. OS gate design revised from plan: instead of hard-blocking Windows, all unsupported platforms get a confirm prompt allowing users with custom plugins to proceed. Better for an OSS project where forks may add platform support.
2. Linux gets a confirm (not just a note) — default yes, acknowledging "not thoroughly tested."
3. `--seed` mode on any platform: warn and proceed (the user chose non-interactive, they know their platform).
4. Detection summary header renamed "Detected:" → "Environment:" to differentiate from the OS detection "Detected: macOS" message.
5. "First run — auto-configuring from environment..." changed to "First run — detecting environment..." (the flow is interactive, not automatic).
