## Decisions Made

1. **One plugin per adapter, not per platform (Decision #43)** — Each plugin implements exactly one contract. GitHub provides 3 separate plugins. No multi-contract plugins. Separation of concerns at the integration boundary. Core to OSS accessibility.
2. **Health events formalized (Decision #44)** — `health.stuck_detected` and `health.trigger_failure` added. Catalog: 28 events, 10 groups.
3. **Minimal tool contract (Decision #45)** — execute + action class + side effects. Safety integration, not behavior prescription. Agent self-extends per PI philosophy.
4. **LLM cost reporting is contractual (Decision #46)** — Every CompletionResult MUST include usage data. Non-negotiable bridge to Safety Layer cost tracking.
5. **People Directory is skeleton, not plugin (Decision #47)** — Always present, config-driven. Infrastructure, not variable.
6. **Event Catalog review fixes (#48)** — Orchestrator receives events via Daemon (not direct subscription). Workspace Manager not a subscriber on task.state_changed (Task Engine calls it directly). L2 docs annotated with Layer 3 update notes.
