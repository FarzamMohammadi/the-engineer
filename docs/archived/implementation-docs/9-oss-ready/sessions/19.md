## Decisions Made

1. **`idempotency_key` is `NOT NULL` and first-class** (on `TaskSchema`, `CreateTaskInput`,
   `task.created` payload, `rowToTask`) — not nullable. Farzam's call: be strict, enforce a
   meaningful unique identity, no placeholder fills / sloppy side effects.
2. **Uniqueness is active-scoped, not global** — the unique index is partial
   (`WHERE state NOT IN ('completed','failed')`). A terminal task frees its key so a reopened
   issue re-triggers cleanly; two *live* tasks can never share a key. Global would silently drop
   re-triggered work forever.
3. **Decomposition child keys are deterministic** — `decomposition:{parentId}:{index}`, so a
   crash-rerun collides on the active index instead of duplicating children (vs a meaningless
   ulid fill).
4. **Delete the now-dead `findByExternalRef` + `idx_tasks_external_ref_active`** — zero callers
   after the rewire; keeping them would be old-dedup infrastructure.
5. **Promote `future-considerations.md` out of archived to live** and prune already-shipped
   entries (CI pipeline, event-bus runtime validation, enum consts, telegram receive); keep
   GitHub receive (still deferred) and genuine future items.
