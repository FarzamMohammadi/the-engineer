# Session 8: Coding Standards Audit — Dashboard

**Date:** 2026-05-13
**Slice:** 03-dashboard (post-completion audit)
**Focus:** Enforce `docs/coding-standards.md` across all Slice 3 code — biome tightening + manual audit

## Summary

Audited all 65 dashboard files (frontend + backend) against `docs/coding-standards.md`. Tightened biome rules to automate everything enforceable, then manually fixed everything biome can't catch. Found and fixed a bug introduced by the sed-based rename.

## What Changed

### biome.json — Rule Tightening
- Added `useFilenamingConvention` project-wide (kebab-case enforcement)
- Re-enabled 6 previously disabled dashboard rules that were convenience overrides, not React necessities
- Reduced dashboard override from 10 disabled rules to 4 (React-essential: `noNamespaceImport`, `noReactSpecificProps`, `useImportExtensions`, `noUndeclaredVariables`)
- Split dashboard override into 2 targeted blocks: vite config (`noDefaultExport` off) vs source code (React-specific rules off)
- Applied `useBlockStatements` auto-fix across 16 files (57 violations)

### Manual Audit — Coding Standards
- **JSDoc on every export:** Added JSDoc to all exported functions, components, types, and interfaces across 65 files
- **Return type annotations:** Added to `mapListRow`, `mapFullTask`, and all formatter functions
- **Newspaper order:** Fixed `use-keyboard-shortcuts.ts` (exported function above private helpers) and `task-table.tsx` (`TaskTable` above `SortButton`)
- **Full names, no abbreviations:** Renamed `res` → `response`, `obs` → `observation`, `evt` → `event`/`domainEvent` across all hooks, pages, and API handlers
- **Function declarations:** Verified all non-inline functions use `function` declarations (already compliant)
- **Guard clauses:** Verified early returns used throughout (already compliant)

### Bug Fix
- `activity-page.tsx` line 43: sed rename changed the data reference from `obs` to `observation` but left the for-of loop variable as `obs`, creating an unused variable referencing a non-existent `observation`. Fixed loop variable to `observation`.

### ApiError Fix
- `api-client.ts`: Fixed parameter property violation — changed from `readonly status` constructor parameter to explicit field assignment
