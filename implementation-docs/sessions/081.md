## Decisions Made

1. **Queue ordering confirmed correct** — `ORDER BY priority DESC, created_at ASC`, no changes
2. **Slot model confirmed correct** — only `active.working` + `active.integrating` consume slots
3. **Fix slot overrun bug** — slot check before parent dispatch in `handleChildrenAllDone`, queue at existing priority (no boost), add `active.integrating → queued` to ValidTransitions
4. **Add retry backoff** — `not_before` timestamp + `consecutive_crash_count` column on tasks table, backoff schedule 1/5/15/30/30 min, max 5 retries then `failed`
5. **Error routing: two paths** — crashes → queued with backoff, deliberate errors → blocked (needs human)
6. **Delete priority aging entirely** — single-user system, user controls priority directly. Cascading simplification: delete `computeAgedPriority`, `applyPriorityAging`, `basePriorities` Maps in scheduler and trigger poller, drain pattern, aging config fields, aging step in tick loop
7. **Cooperative shutdown via pull model** — `shutdownRequested` flag checked between phases (same pattern as preemption), no EventBus event needed
8. **State rename `intake` → `requirements_gathering`** — co-founder override of panel recommendation, separate migration from schema additions
9. **Preemption confirmed correct** — 20-point threshold, two-strike timeout, one per tick
10. **Rework flow confirmed correct** — restart from requirements gathering after review feedback
11. **Observability additions** — info-level dispatch logging, `preemption.completed` event, slot utilization in daemon state

Panel findings incorporated:
- `consecutive_crash_count` column instead of `state_transitions` query (all 5 panelists)
- No priority boost magic number — queue at existing priority (Torvalds, Engineer Persona)
- Pull-based shutdown flag instead of EventBus event (Engineer Persona, Hipp)
- Delete aging entirely (Engineer Persona, endorsed by co-founder)
- `active.integrating → queued` transition missing in ValidTransitions (Architect)
- Separate rename migration from additive schema changes (Hipp, Architect)
- Deferred: `queued → failed` cancellation transition (Torvalds, tracked in deferred items)
