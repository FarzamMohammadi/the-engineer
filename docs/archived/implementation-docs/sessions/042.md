## Decisions Made

1. **Include `repoScope` in knowledge ID hash** — `knowledgeId(scope, repoScope, key, body)` hashes `scope:repoScope:key:body`. Same knowledge in different repos gets distinct IDs. Strict isolation over content-addressable deduplication.

2. **Omit Registry from WorkspaceManager constructor** — PR operations (createPR, mergePR, etc.) need GitHostingAdapter via Registry, but those plugins aren't built until Phase 14b. Constructor takes only `EventBus + WorkspaceConfig`. Documented in class JSDoc for when to add it.

3. **`getLatestCheckpoint` uses `rowid DESC`** — Timestamps can collide when checkpoints are created in the same millisecond. SQLite rowid is guaranteed monotonically increasing, making ordering reliable without adding artificial delays.
