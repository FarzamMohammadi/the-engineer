## Bugs Found & Fixed

**SSE subscription disconnect:** `useSse()` dispatched events to `listenersRef.current` (a ref-local Map), but `useSseSubscription()` registered callbacks in `sseListeners` (a module-level Map). The two maps never communicated, so SSE subscriptions silently dropped all events. Fixed by making `useSse()` dispatch to the module-level `sseListeners` map.

## Decisions

1. **SSE consolidation:** Single module-level listener map instead of ref-local. Simpler, works with React strict mode, and avoids the dual-map disconnect.
2. **Chart wrapper:** Lightweight `ChartContainer` + `ChartTooltip` + `CHART_COLORS` instead of the full shadcn/ui chart component. The full version is ~200 lines of config-driven abstraction we don't need.
3. **Keyboard shortcuts:** GitHub-style "g then key" chord pattern (g+o, g+t, g+a, g+m, g+e). 500ms timeout between keystrokes. Disabled when focus is in input/textarea.
4. **Error endpoint aggregation:** Backend `/api/errors` merges 3 sources (failed tasks with transition reasons, error-level observations, error domain events) into a uniform `ErrorEntry` shape. Frontend gets one clean list, no N+1 queries.
5. **Activity page architecture:** Backfills from `/api/observations` + `/api/events` on mount, then appends SSE events in real-time with ID-based deduplication. 500-item cap prevents memory growth.
