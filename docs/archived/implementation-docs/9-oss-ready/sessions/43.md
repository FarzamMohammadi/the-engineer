## Decisions Made

1. **Delivery's live git-hosting interaction is built as dark shells** *(Farzam's pick)*. The delivery
   orchestrator sub-phases own real routing, skip-gates, and observability now; the git and
   git-hosting side-effects (`push`, `createPR`, `mergePR`) carry `TODO(farzam)` and land at the S7
   wiring, because their final form depends on the finalized task state (S5 cutover) and the
   `detectPrEvents` contract (S6) + external re-entry (S7). `await-review` has nothing to await until
   then, so in S4 it only routes into the wait. Zero throwaway against the legacy `task.review` shape.
2. **`refine` carries a 5-verdict typed vocabulary** *(Farzam's pick — the kickoff's 4-verdict list only
   covered advance + jump)*. `ship`/`revise`/`rework_execution`/`rework_planning`/`rework_requirements`
   total over the three route verbs and honor D13's "fixes in place, repeats to re-check (cap 3), jumps
   out only when it cannot fix." `rework_code`→`rework_execution` so it is not confused with refine's
   own inline fixes.
3. **The new review-lens enable-list is a new `OrchestratorConfig.review.lenses` field** (default
   `["self-review"]`), separate from the legacy `rrpir.review_phases` (different vocabulary, deleted at
   S5). All four lenses are gated by membership; `self-review` is in the default. Bounded build-dark
   duplication that collapses at the cutover.
4. **`arbitrate` precedence** (Core's call, documented in `pipeline.ts`): `pr_merged` (terminal) >
   `pr_comments` > `pr_merge_conflict` > `pr_ci_failure` > `pr_ready_to_merge`. Satisfies the slice's
   mandate (feedback beats ready-to-merge) and keeps a merge terminal; the rest is sensible ordering.
5. **A lens-factory pattern** (`review/lens.ts`) over four near-identical lens files — the four lenses
   share skip + next + agent-step wiring, so the duplication is compressed (Metz/Muratori). Each lens
   file declares only name + role + instructions. Diverges from the slice's "copy security.ts"
   walkthrough prose (reconcile in the S9 docs sweep; code is truth).
