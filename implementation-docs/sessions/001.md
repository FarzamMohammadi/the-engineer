# Session 001 — 2026-03-06

## What Happened

Started from zero. Explored how to make the agent agnostic, iterated through several approaches, and landed on our own protocol. Set up the development documentation workspace. Made all foundational decisions.

Key iteration: started with per-agent wrappers (CLAUDE.md, GEMINI.md, etc.) → moved to AGENTS.md standard → rejected all of it in favor of our own protocol (BOOT.md). Then removed BOOT.md and memory/ too — both were premature implementation artifacts. Architecture comes first, artifacts come from the architecture.

## Decisions Made

1. **Our own agent-agnostic protocol** — rejected accommodating every agent's conventions. We define the protocol, agents adapt to us.
2. **Docker-first deployment** — always-running daemon in a container. Portable to any VM/cloud.
3. **Python stack** — best LLM ecosystem, largest contributor pool.
4. **Registry pattern for modularity** — triggers, comms, LLMs, tools, workflow phases all pluggable.
5. **PI-inspired minimalism** — small system prompts, few broad tools, single agent, full context visibility, self-extension.
6. **Full engineering lifecycle** — 14 phases from intake to memory update. The agent gathers requirements from real people, doesn't just "go build."
7. **Architecture first, code never (until approved)** — all deliverables are documentation until Farzam says so.
8. **temp-docs/ as sole dev workspace** — active.md, sessions/, philosophy.md, architecture/. Everything for builders lives here.
9. **No premature artifacts** — removed BOOT.md and memory/. These are outputs of architecture, not inputs.
10. **Clear separation** — temp-docs/ is for us (builders). Everything else in the repo is for The Engineer (the agent). Don't mix them.
