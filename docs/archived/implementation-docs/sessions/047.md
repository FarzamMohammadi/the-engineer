## Decisions Made

1. Octokit mocked via `protected` field on plugin class, replaced after `initialize()` via cast — consistent with project mock pattern
2. GitHubCommPlugin capabilities: `["send", "sync", "issue_management"]` — `receive` deferred (requires People Directory auth, message routing, interrupt design)
3. Doctor checkGitHubConnectivity() is sync, token-presence only (no live API call) — keeps doctor synchronous per existing design
4. State sync via Daemon subscription to `task.state_changed`, not plugin self-subscription — per Decision #40 (comm plugins are dumb transport)
5. Query handler extracted to `src/core/daemon/query-handler.ts` for Biome cognitive complexity management
6. `receive` capability documented in `future-considerations.md` — it's for People Directory members communicating WITH The Engineer mid-flow (interrupts, questions, direction), not triggering
7. ExternalRef mapping uses existing `parseGitHubUrl()` from github-shared + `toExternalRef()` — ExternalRefSchema already in task.ts
8. Plugin health in `engineer status` deferred to Phase 15 (requires IPC or DB persistence of in-memory Registry state)
