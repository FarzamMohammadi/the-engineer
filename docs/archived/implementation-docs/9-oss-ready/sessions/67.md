## Decisions Made

1. **Ship v1.0.0 as a GitHub release, not npm.** npm deferred until a real consumption story (stable API / out-of-tree SDK / strong exact-stack demand); `package.json` stays publish-capable. Recorded in `future-considerations`.
2. **CLI-only package** for v1 — no importable SDK (additive later, non-breaking).
3. **Docs site = VitePress presenting `docs/` directly** (one source of truth), default theme + custom CSS, deployed to GitHub Pages via `docs.yml`, no custom domain. The internal build journal is excluded and linked out.
4. **Cut:** demo-as-code (`pnpm demo`/`demo/`), the design-history archive (covered by `docs/archived/`), `llms.txt`.
5. **v1.0.0 posture:** version single-sourced in `package.json` (the dashboard inherits it), a dynamic GitHub version badge (no hardcoded version), and a "young / working / feedback-welcome" voice in README + SECURITY.
6. **Demo = a real-system marketing video, produced last,** on a disposable branch. Highest quality via lossless Playwright frames + Remotion at 8K (never `recordVideo`), then embed the GIF and **tag `v1.0.0`** as the very last step. Scripted automation (Playwright/`gh`/`claude`/ffmpeg/Remotion via Bash) over desktop GUI control — reusable as a `pnpm demo`-style pipeline.
7. **Reordered local `main`** so the RRP-artifacts commit precedes the build commits, with correct timestamps.
