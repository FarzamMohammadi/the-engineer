## Decisions Made

1. **Two-method Safety Layer API** (#129). Split `evaluate(SafetyQuery)` into `evaluateAction()` (Gate 2 — binary gate check by Action Pipeline) and `consultJudgment()` (passive consultation by Orchestrator). Different callers, different intent, clearer contracts. Both return `SafetyVerdict { allowed, action, reason, warnings? }`.

2. **Custom `matchesPathPattern()` over adding a glob dependency** (#130). ~30-line implementation supporting `*` (single segment), `**` (recursive), and literals. Different from EventBus's dot-separated `matchesPattern()`. Avoids adding a dependency for a focused use case.

3. **Snapshot after every cost event** (#131). Cost events are infrequent (one per LLM call). A `_meta` upsert is microseconds. No timer, no counter, no configurability — simple.

4. **UTC midnight/first-of-month for time windows** (#132). Deterministic, no config needed. Window rollover detected on every cost event by comparing timestamp against current window boundary.

5. **Simple threshold parser for autonomy** (#133). Parses `"<metric> <op> <value>"` patterns (e.g., `"scope > 5 files"`). Unknown thresholds → `ask_human` (fail-safe). Exported as pure functions for testing.

6. **`ContactInfo.plugin_id` = channel name** (#134). People Directory doesn't know about the Registry. `resolveContact` sets `plugin_id` to channel name. Orchestrator maps channel → plugin ID.

7. **Include `getTimeoutPolicy()` now** (#135). Daemon (Phase 12) needs it (Protocol P11). Trivial accessor returning `config.response_timeout`. Added to keep Safety Layer interface complete.

8. **`evaluateAction` checks merge policy** (#136). When `actionClass === "merge"`, checks `config.merge.auto_merge` for the repo. Connects to Task Engine's conditional permission for merge (Session 039 Decision #3).
