# Session 30 — 2026-05-24

## What Happened

Post-Slice-6 sweep refinement — one defect class the Session 29 sweep
missed: **duplicated functions** (not just literal constants) across
sibling plugins.

The env allowlist (`LLM_ENV_ALLOWLIST` + `LLM_ENV_PREFIX_ALLOWLIST`),
`buildLlmEnv()`, and `appendStderr()` were copy-pasted verbatim across
all three LLM plugins (`claude-code-llm`, `gemini-cli-llm`,
`opencode-llm`) — with a `"canonical copy in claude-code-llm.ts — keep
in sync"` comment on two of them. The comment itself was an explicit
admission of the § 11 violation.

Extracted to `src/plugins/llm/subprocess.ts` as the single
authoritative copy. Each plugin now imports from there. Bundled
plugin-author docs and `docs/plugins/llm/README` updated to point at
the new location.

Net: -77 lines. No behavior change. 2446 unit + 39 integration tests
still pass. Commit `1c47192`.

## Decisions Made

1. **Cross-plugin function duplication is in § 11's scope.** The sweep
   memory's "Every constant value lives in one place" bullet only
   called out literals (model ids, magic numbers). Functions that
   happen to be identical text across siblings are the same violation
   with worse blast radius — they tend to drift unnoticed because each
   file reads correctly in isolation. The sweep memory was enhanced
   with this example so future sweeps grep across sibling directories
   for duplicated identifier blocks.

2. **Refactor lives in Slice 6 history, not Slice 7.** Even though
   Slice 6 was already marked closed in Session 29, this is a sweep
   defect Slice 6 emitted. Folding it into the Slice 6 entry (Sessions
   25–30) keeps the slice's quality story honest, rather than
   surfacing it as a Slice 7 carry-over.
