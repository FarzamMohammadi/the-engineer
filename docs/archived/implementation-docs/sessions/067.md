## Decisions Made

1. LLM plugins are self-contained (no shared `buildLlmEnv` extraction) — each plugin copies the pattern with a sync comment pointing to the canonical version
2. `engineer init` uses single-select for LLM provider (only one at a time), multi-select for everything else
3. Plugin discovery is config-file-driven — manifest `enabled` field controls init pre-check, not loading
4. Default models: Claude Code = `claude-sonnet-4-20250514`, OpenCode = `opencode/gemini-3.1-pro`, Gemini CLI = `gemini-2.5-pro`
5. Rate limit detection: Gemini detects from stdout (`status: "error"` in result event) + stderr (kill on retry pattern). OpenCode detects from stderr only. Both report via `getQuotaStatus()` → Core pauses daemon.
6. Dashboard shows `N/A` (not `$0.00`) when cost data is null (provider doesn't report cost)
7. Blocked task reasons surfaced from `state_transitions` table to dashboard kanban + task detail
8. "Agent-Assisted Everything" added as core philosophy — contribution guides written as agent prompts, zero-pain setup for any user+agent pair
