## Decisions Made

1. Capabilities: `send` only — `receive` deferred for same reasons as GitHub (People Directory auth, message routing, interrupt handling)
2. grammy minimal surface: `new Bot(token)` for construction, `bot.api.sendMessage()` for sending, `bot.api.getMe()` for health — no `bot.start()` (no polling)
3. `formatMessage()` varies output by stored `parse_mode` (MarkdownV2/Markdown/HTML) with graceful fallback to MarkdownV2 before `initialize()`
4. `chat_id` as string type — Telegram group chat IDs are negative numbers, string avoids precision issues
5. `@types/node-fetch` added as devDependency — grammy's type declarations reference `node-fetch` without bundled types
6. Doctor check is sync, env-var-presence only (no live API call) — matches GitHub pattern
