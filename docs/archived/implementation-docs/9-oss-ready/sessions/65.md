## Decisions Made

1. Health scope = both plugin-health and task-health, full; pillar reach = full enforcement pipeline,
   siblings verify-only; keep the periodic services independent (cross-link, don't unify).
2. Two contract-fix behavior changes only: provider `daily_requests` resets daily (windowed,
   restart-safe); daily/monthly breaches terminate in-flight + one global alert.
3. Delete dead surface: `cost.quota_exhausted` event + its `/quota` block; `token_totals`/`daily_tokens`.
4. Plugin health stays advisory (no gating), documented + test-locked; the one new feature is the
   `failed→healthy` recovery notification (flap-safe, source-deduped).
5. Current health state → a `_meta` single-row cache (overwrite), not a per-cycle event.
6. Observability ceiling: milestones + transitions edge-triggered + named; liveness via last-run;
   rendered into existing pages; no net-new pages.
